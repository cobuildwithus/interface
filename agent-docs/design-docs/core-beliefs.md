# Core Beliefs

1. Keep repository-local docs as the system of record for agent reasoning.
2. Keep AGENTS files short; use them as routing tables, not encyclopedias.
3. Encode durable constraints in docs and scripts so they are mechanically enforceable.
4. Prefer clear boundaries over ad-hoc flexibility to reduce architectural drift.
5. Treat plans and debt tracking as versioned artifacts, not external notes.
