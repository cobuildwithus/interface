# Product Sense

## Primary User Journeys

1. Discover and evaluate goals

- Users navigate goals, builders, rounds, and discussion context.
- UI should make purpose and next action clear in under one screen.

2. Fund and allocate

- Users execute swaps/contributions with clear wallet/auth state.
- Value-transfer actions must surface status and error outcomes clearly.

3. Participate socially

- Users interact via Farcaster/X-linked context and profile activity.
- Social actions should keep identity and source attribution legible.

4. Manage identity and settings

- Users can link accounts, view profile status, and manage preferences.
- Wallet identity transitions must be explicit and safe.

## Product Communication Constraints

- Use participation-focused language, not investment framing.
- Prefer terms like participants/builders/contributors/holders.
- Avoid guaranteed-return, yield, or trading-advice phrasing.
- Always include risk caveats where financial interpretation is possible.
- Use "Farcaster" (not "Warpcast") in user-facing copy.

## UX Decision Rules

- High-impact actions (swap, permission, account linking) must have clear confirmation/error states.
- Prefer explicit state labels over implied behavior in transactional flows.
- Defer copy that could be construed as legal/financial advice for human review.

## Update Triggers

Update this doc when changing:

- user journeys or major navigation flow,
- value-transfer or onchain action UX,
- product copy constraints or naming rules.
